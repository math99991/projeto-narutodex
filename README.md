# projeto-narutodex
Projeto acadêmico TCD de site com catálogo de personagens e vilas ninja do desenho Naruto.

## Objetivo

Organizar informações sobre personagens e vilas em uma interface responsiva.

## Funcionalidades planejadas

- Listagem de personagens
- Pesquisa de personagens
- Filtro de favoritos
- Listagem de vilas ocultas
- Modo claro e modo escuro
